# EdemPlayer — IPTV-плеер с архивом

IPTV-плеер для Edem: каналы с архивом и программой передач на 7 дней, медиатека VPortal (фильмы, сериалы, «продолжить просмотр»),
голосовой и текстовый поиск, управление с пульта, мышью и клавиатурой. Windows (Electron); интерфейс обновляется с GitHub без переустановки.

## Установка (Windows)
1. Скачайте полный пакет `EdemPlayer-<версия>-win-x64.zip` (раздел Releases) и распакуйте — получится папка `EdemPlayer`.
2. Запустите `EdemPlayer\EdemPlayer.exe`. Полный экран — F11 или двойной щелчок по видео; сразу на весь экран: `EdemPlayer.exe --fullscreen`.
3. Обновления интерфейса программа скачивает сама из этого репозитория (файл `update/manifest.json`) и предлагает перезапуск.

## Сборка из исходников
```
npm install
npm start            # запуск
npm run dist         # dist/EdemPlayer-<версия>-win-x64.zip
npm run manifest     # пересчитать update/manifest.json после изменения www и версии
```
Выпуск обновления интерфейса: изменить файлы в `www`, поднять `version` в `package.json`, `npm run manifest`, отправить в `main`.
Если менялись `electron/*.js` — поднять `edemShell` и выпустить полный пакет в Releases.

## Подключение (⚙ Настройки → Подключение)
Настройки разделены на вкладки: Подключение, Языки, Программа передач — они общие и не зависят друг от друга.
Канал без архива открывается с программой передач: прошедшие и будущие передачи видны серым, выбрать можно
только текущую (прямой эфир); если поток не даёт перематывать,
кнопки перемотки скрыты и перемотка отключена — остаются пауза и громкость.

При первом запуске сразу открываются настройки. Способ подключения и все данные (ссылка, ключ, домен, файл) хранятся только на устройстве.

- **По ссылке** — прямая ссылка на плейлист из личного кабинета. Список скачивается при каждом запуске.
- **По ключу доступа** — ключ и домен каналов из личного кабинета. Адреса каналов собираются как
  `http://<домен>/iptv/<ключ>/<номер канала>/index.m3u8`; номера и названия каналов берутся из шаблона —
  последнего списка, загруженного по ссылке или из файла (сохраняется автоматически).
- **Файл плейлиста** — .m3u/.m3u8 с диска; хранится на устройстве.

## Программа передач
Источники XMLTV (можно .gz) просматриваются по порядку: сначала добавленные вами в Настройках (можно несколько,
порядок меняется кнопкой ↑), затем адрес из самого плейлиста (url-tvg), затем встроенные
`http://epg.it999.ru/edem.xml.gz` (названия каналов как у Edem), `https://iptvx.one/epg/epg.xml.gz` (самый полный
бесплатный: РФ, СНГ, зарубежье, 14 дней с прошедшими, ~60 МБ) и `http://epg.it999.ru/epg.xml.gz` (запасной).
Встроенные удалить нельзя. Если в источнике у канала несколько одноимённых записей, берётся та, где есть передачи на сегодня.
Следующий источник скачивается, только если в предыдущих нашлись не все каналы. Список каналов без программы — внизу Настроек.

## Язык интерфейса
Русский, English, Українська, Deutsch, Français, Español. По умолчанию — язык ОС; другой выбирается в
Настройки → Языки → «Язык интерфейса» (хранится на устройстве). Переводы — `www/js/i18n.js`, новый язык добавляется
словарём. Голосовой поиск распознаёт русскую речь.

## Главный экран
В списках каналов сначала недавно просмотренные (⟲, последний — первым), затем по алфавиту.
В разделе первая плитка — «Все каналы раздела», дальше буквы.
Строка навигации вверху («EdemPlayer › Настройки › Языки») кликабельна мышью и доступна с пульта (стрелка вверх).
Первая строка: ⚙ Настройки, 🔍 Поиск, ★ Избранное, Все каналы; дальше — категории из плейлиста.

## Медиатека Edem (VPortal)
Настройки → Подключение → «Ссылка на медиатеку»: строка из кабинета вида `portal::[key:…]http://…/api/v1/`
(хранится на устройстве, переносится через облако/файл). На главном экране появляется «🎬 Медиатека»: разделы
сервера (фильмы, сериалы…), «🎭 Жанры» (первый пункт — «Все жанры»), другие фильтры (годы). Списки догружаются
страницами; кнопки «По алфавиту» / «Новые сверху». Карточка фильма — «▶ Смотреть» и варианты качества; сериал —
сезоны и серии. Поиск ищет и в медиатеке. Протокол — как в открытых плагинах ProIPTV / ottplay (`js/vod.js`).

## Перенос настроек (⚙ Настройки → Облако и файл)
**Облако.** Настройки привязаны к коду синхронизации вида `2NMF-HDAT-5THF`: он создаётся при первом «Сохранить в облако»
и запоминается на устройстве (показан на вкладке). На другом устройстве: экран приветствия → «☁ Загрузить настройки
из облака или файла» → ввести код → «Загрузить из облака».
**Файл.** «Сохранить в файл» — `EdemPlayer-settings-ГГГГММДД.json` в папку «Загрузки»; «Загрузить из файла» — на другом
устройстве. В файле ссылка и ключ в открытом виде.

### Подробности облака
Резервная копия (подключение, языки и ручная разметка, программа передач, избранное, история, громкость, язык
интерфейса) хранится в бесплатном облаке TextDB.online, без регистрации. Имя записи — `edp-` + SHA-256 от кода
синхронизации (необратимо), содержимое зашифровано AES-GCM ключом, выведенным из кода (PBKDF2).
Ограничения сервиса: 500 записей в сутки с одного IP, запись удаляется через год без обновлений.
**Свой сервер.** Если textdb.online недоступен, положите `tools/cloud-server/edp-cloud.php` на любой хостинг/VPS с PHP
и укажите его адрес в поле «Адрес облачного хранилища» (на каждом устройстве). Сервер хранит только хэш-имена и шифротекст.

## Языки каналов
Настройки → Языки → «Языки каналов»: «Все языки», «Снять все» (затем отметьте нужные языки) или отметки по одному; если не отмечено ничего — показываются все каналы. Каналы на невыбранных языках скрыты в категориях,
«Все каналы» и поиске; избранное не фильтруется. Язык берётся из `tvg-language`, иначе определяется по группе канала
по суффиксу страны в названии («RFM TV HD FR», «Rai 1 IT»), по множеству форм названия группы: «Армения», «армянские», «Армянский», «Armenian», «ARM», метки «(UA)» в названии канала и т. п.;
остальные считаются русскими. Ручная разметка: язык категории — Настройки → Языки → «Языки категорий»;
язык канала — долгое OK / правая кнопка на канале или кнопка 🌐 на экране программы. Всё хранится на устройстве.

## Поиск
Плитка «🔍 Поиск», Ctrl+F или кнопка поиска на пульте. Ищет каналы и передачи за 7 дней.
Можно сразу печатать; понимает «россия двадцать четыре» → Россия 24, «тэ эн тэ» → ТНТ, «дискавери» → Discovery.
Голос — кнопка «🎤 Голос»: распознавание офлайн (Vosk, русская модель встроена), интернет не нужен.

## Выход
«Назад» на главном экране, крестик окна или Alt+F4 — приложение спрашивает «Выйти из EdemPlayer?».

## Если нет изображения или звука
Часть зарубежных HD-каналов идёт в HEVC (H.265) или со звуком Dolby AC-3. Встроенный плеер HEVC в Windows
декодирует аппаратно (если видеокарта умеет), AC-3 — нет. В таких случаях на экране будет сказано, какой формат
не поддерживается, а клавиша **V** / кнопка «Открыть в VLC» передаст этот же поток (в том числе архив) во внешний
плеер — VLC, PotPlayer или mpv (если установлены). Клавиша **I** / кнопка ℹ — сведения о потоке (кодеки, кадры, ошибки).

## Управление
| Где | Пульт / клавиатура | Мышь |
|---|---|---|
| Списки | стрелки, OK (Enter), «Назад» (Esc/Backspace) | наведение, щелчок, боковая кнопка «назад» |
| Избранное | удерживать OK, или F / жёлтая кнопка | правая кнопка или звёздочка |
| Плеер | + / − громкость, M — без звука, ← → ±30 с (удержание ускоряет), ⏪ ⏩ ±5 мин, OK — пауза, PageUp/PageDown (Канал ±) — следующая/предыдущая передача, ↓ — кнопки, «Назад» — к программе | кнопки, щелчок по полосе, щелчок по видео — пауза, колесо — громкость |

## Разработка
```
npm install
npm start          # запуск из исходников
npm run dist:dir   # сборка в dist\win-unpacked
npm run dist       # portable + установщик (на Windows)
```
Отладка: Ctrl+Shift+F12 — инструменты разработчика.

## Устройство
- `www/` — всё приложение (HTML/CSS/JS), общее для всех платформ.
  - `js/config.js` — значения по умолчанию: источники программы передач, формат архива, шаги перемотки.
  - `js/m3u.js` — разбор плейлиста (`group-title`/`#EXTGRP`, `tvg-rec`/`catchup-days`, `catchup-source`).
  - `js/i18n.js` — переводы интерфейса.
  - `js/search.js`, `js/voice.js` — поиск и голосовой ввод (`vendor/vosk.js`, `models/` — модель Vosk, лицензия Apache 2.0).
  - `js/vod.js` — медиатека Edem (VPortal).
  - `js/cloud.js` — резервная копия настроек в облаке.
  - `js/source.js` — источник списка: ссылка / ключ + домен / файл.
  - `js/catchup.js` — адрес архива (по умолчанию `?utc={utc}&lutc={lutc}`, также flussonic и шаблоны `catchup-source`).
  - `js/epg-worker.js` — потоковый разбор XMLTV (.xml/.gz) в фоне, кэш в IndexedDB на 6 часов.
  - `js/player.js` — hls.js, архив с начала передачи, перемотка (в окне потока или перезапросом архива).
  - `js/nav.js`, `js/app.js` — навигация пультом/мышью и экраны.
- `electron/` — оболочка для Windows (Linux/macOS собираются так же).

## Следующие платформы
Android / Android TV / проекторы: тот же `www/` через Capacitor (`webDir: www`,
`android.allowMixedContent: true`, плагин CapacitorHttp для обхода CORS, leanback-манифест для Android TV).

## Если что-то не работает
- **Архив не открывается** — формат архива провайдера может отличаться: поменяйте `defaultCatchupSource` в `www/js/config.js`.
- **Нет программы передач** — укажите адрес XMLTV в Настройках.



## 1.7.0

### Медиатека — отдельная вкладка настроек
«Настройки → Медиатека»: ссылка `portal::[key:…]http://…/api/v1/` хранится отдельно от способа подключения ТВ (ключ на экране скрыт). Кнопка «Проверить связь» показывает подробный отчёт: адрес API, время ответа, ответ сервера на каждый вариант запроса (ключ в отчёте не выводится).

Запросы к API медиатеки идут из основного процесса программы (Node), только методом POST, с заголовками `User-Agent: OTT Navigator/1.6.9.4 (Linux; Android 11)`, `Content-Type: application/json`, `X-Api-Key: <ключ>`. Тело — JSON с ключом; программа перебирает варианты тела (key+mac+app, только key, key+mac OTT, форма) и запоминает тот, на который сервер ответил без ошибки. Сетевые ошибки показываются точно: DNS, отказ в соединении, таймаут, обрыв, TLS. Ответ сервера вида `{"type":"error","description":…}` выводится как есть.

### Просмотренные ранее
- В каждом разделе медиатеки первой плиткой — «Просмотренные ранее» (в корне медиатеки — все просмотренные). Порядок — по убыванию даты просмотра; у сериала одна запись с последней просмотренной серией. Долгое OK — открыть карточку или удалить из списка.
- Фильм и серия продолжаются с места остановки (в карточке — «▶ Продолжить с …» и «↺ Сначала»); если не смотрели или досмотрели — с начала. Место сохраняется каждые 5 секунд и при выходе.
- В сериале — кнопки ⏮ ⏭ (и PgUp/PgDn, Channel ±) для предыдущей/следующей серии, в том числе через границу сезонов; после окончания серии автоматически начинается следующая. Список серий сезона — в порядке сервера, OK сразу запускает серию.
- История и места остановки переносятся через облако и файл. Очистить — «Настройки → Медиатека».

### Облако: Яндекс.Диск
«Настройки → Облако и файл → Где хранить копию»: Яндекс.Диск (по умолчанию) или свой сервер. Для Яндекс.Диска нужен OAuth-токен: кнопка «Получить токен» открывает Полигон Яндекс.Диска (https://yandex.ru/dev/disk/poligon/) → «Получить OAuth-токен» → вставить в поле. Копия — файл `edp-<хэш кода>.json` в папке `EdemPlayer` на вашем Диске, содержимое зашифровано кодом синхронизации. Токен в облако не передаётся, только в файл настроек.

## 1.9.0

## 2.0.0 — новое оформление
- «Ночное стекло»: глубокий фон с мягким цветным свечением, стеклянные карточки с тонкой светлой кромкой, градиентные акценты (сине-фиолетовые), кнопки-«пилюли».
- Выбранный элемент приподнимается над остальными: всплывает, отбрасывает тень, получает светящуюся рамку, по нему проходит блик; у постеров слегка увеличивается картинка, у логотипов — плашка.
- Плитки категорий — каждая своего оттенка, с крупным полупрозрачным значком (по смыслу: новости, спорт, детские, кино…) и «стопкой» логотипов каналов; разделы медиатеки — веером из трёх постеров и количеством фильмов.
- Экраны появляются плавно, плитки — волной; в программе передач текущая передача с красной кромкой и «пульсирующей» меткой; в плеере — стеклянные круглые кнопки и светящаяся полоса прогресса.
- При включённом в системе «уменьшении движения» анимации отключаются.
- «Настройки → Вид → Вид списков»: плитки или строки — теперь для всех экранов: категории, буквы, каналы, медиатека (разделы, фильмы с маленьким постером, франшизы, сезоны, «просмотренные»), поиск.

## 2.1.0 — обновления с GitHub без перекачки Electron
- Программа теперь — папка `EdemPlayer` (оболочка Electron + открытые файлы интерфейса в `resources\app`), а не один portable-exe: запускается быстрее (не распаковывается при каждом старте).
- Обновление интерфейса: при запуске (через 20 с) и раз в 6 часов программа читает `update/manifest.json` из репозитория GitHub (`package.json → edemUpdate.repo`), при новой версии скачивает только изменившиеся файлы (с проверкой SHA-256; зеркало — jsDelivr), складывает их в `%APPDATA%\EdemPlayer\app-next` и предлагает перезапуск; при следующем запуске новая копия подменяет прежнюю. Голосовая модель не перекачивается. «Настройки → Система»: версия, «Проверить обновления», «Перезапустить».
- Если новой версии нужна новая оболочка (`edemShell` в манифесте больше, чем у установленной), программа сообщит, что нужно скачать полный пакет с GitHub (Releases).
- Выпуск обновления: изменить файлы в `www`, поднять `version` в `package.json`, выполнить `npm run manifest` и отправить на GitHub.
- Поиск: заставка, «Недавние каналы» и «Продолжить просмотр» при пустом запросе, заголовки с количеством, логотипы каналов у найденных передач.
- Франшизы: объединяются не только сериалы, но и выпуски передач и фильмы одной серии («Поле чудес. Выпуск от …», «Вечерний Ургант (15.03.2022)», «Звёздные войны: …»); выпуски внутри — по дате (новые сверху).

## 2.1.1
- Первое обновление через GitHub: в «Настройки → Система» видно, что интерфейс обновлён с GitHub.

## 2.1.2
- История поиска: при пустом поле — «пилюли» прошлых запросов, последние первыми (до 30). Запрос запоминается, если на нём остановились и что-то нашлось, после Enter, голосового ввода или перехода к результатам. OK — искать снова, долгое OK — удалить, «✕ Очистить» — всё. Переносится через облако и файл.

## 2.1.3
- Обновления перенесены в отдельную вкладку «Настройки → Система»; вкладки настроек — в одну строку.

## 2.1.4
- Вкладки настроек компактнее; если не помещаются — переносятся на вторую строку (исправлена горизонтальная прокрутка из 2.1.3).

## 2.1.5
- «Система → Обновления»: видно, с какого адреса пришло обновление и какой не ответил.
- Оболочка (войдёт в следующий полный пакет): обновления запрашиваются по номеру последнего коммита (API GitHub), поэтому и raw.githubusercontent.com, и зеркало jsDelivr отдают точно свежие файлы, без 12-часового кэша ветки.

## 2.1.6
- Постеры на всех плитках медиатеки: для ещё не открытых разделов фоном берётся одна короткая страница (постеры и количество, хранится сутки); «Год» — самые свежие постеры, «Жанры» — из разных разделов. Длинные названия на плитках — в две строки вместо обрезки.

## 2.1.7
- Медиатека → Год → выбор жанра: первым пунктом «Все жанры» (все фильмы года), затем жанры. Список «год + жанр» — пересечение списка года и списка жанра (точно, даже если сервер не умеет фильтровать по двум условиям); оба списка хранятся на устройстве и обновляются фоном.

## 2.1.8
- Строка пути (EdemPlayer › Настройки › …): выделение — «пилюля» с мягким градиентом и свечением вместо рамки; логотип при выделении слегка увеличивается; строка не сдвигается при переходах.

## 2.2.0
- **Личные данные скрыты**: ссылка на плейлист, ключ доступа, домен, ссылка медиатеки, токен Яндекс.Диска, адрес своего облака и коды синхронизации — звёздочками, кнопка «👁» показывает/скрывает. В сообщениях об ошибках, сведениях о потоке, проверке связи и списке источников программы передач личные значения и токеноподобные части адресов заменяются на `***`.
- **Android TV / проекторы (Android 9+)** — папка `android`: тот же интерфейс в WebView, «родная» оболочка на Java (HTTP без CORS, «Назад» на пульте, системное распознавание речи, внешний плеер VLC/MX, выбор и сохранение файлов, обновление интерфейса с GitHub). Сборка: `android\собрать_apk.bat` (нужны Android Studio или JDK 17 + Android SDK) → `EdemPlayer-TV-<версия>.apk`. Установка: флешка/«Отправить файлы на ТВ» или `adb install`.
- Совместимость со старым WebView: распаковка программы передач без DecompressionStream (встроенный pako), CSS без `inset`/`aspect-ratio`.

## 2.2.1
- Медиатека: ответы сервера с невидимыми символами (неразрывные пробелы, символы нулевой ширины, табуляции и переводы строк внутри строк) теперь разбираются — загрузка больших разделов («фантастика») больше не обрывается с «сервер вернул не JSON». Если ответ всё же не разобран, в сообщении указано, какие необычные символы в нём есть.
